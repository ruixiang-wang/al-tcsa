# AI-TCSA: AI for Theoretical Calculation of Synthetic Ammonia

AI-TCSA (AI for Theoretical Calculation of Synthetic Ammonia) is a small,
self-contained toolkit for modeling and interpreting NO* reduction
energy steps (G0 / G1 / G5) with machine learning and symbolic
regression:

- XGBoost regression with Bayesian hyper-parameter search
- Model stability across random seeds
- SHAP-based global & local interpretability
- SISSO-style analytical formulas evaluated on the same dataset

The repository is designed so that a new user can reproduce all
experiments with a single Python environment and the CSV data under
`data/raw/`.

---

## 1. Repository Layout

From the project root (`AI-TCSA/`):

- `data/`
  - `raw/`
    - `NO-G0-all.csv`
    - `NO-G1-all.csv`
    - `NO-G5-all.csv`  
    Original NO* data used by all pipelines.
  - `sisso/`  
    Will contain SISSO-formatted `train.dat` files
    (`G0/train.dat`, `G1/train.dat`, `G5/train.dat`) generated by
    our helper scripts.

- `modeling/`
  - `train_models_bayes.py`  
    Train XGBoost regressors for G0/G1/G5 with Bayesian optimization
    and save the best pipeline per tag.
  - `eval_models_over_seeds.py`  
    Re-train a given tag with multiple random seeds to check
    performance stability and log metrics.

- `xgb_analysis/`
  - `plot_xgb_predictions.py`  
    Scatter plots of predicted vs. DFT (Gₙ(eV)) for all tags.
  - `shap_summary_xgb.py`  
    SHAP computation + global summary (bar & beeswarm) per tag.
  - `shap_dependence_xgb.py`  
    SHAP dependence plots: SHAP value vs. feature value, with trend
    curves.
  - `shap_force_xgb_batch.py`  
    SHAP force plots for a batch of samples per tag.
  - `shap_force_catalysts.py`  
    SHAP force plots for a list of named catalysts on G0.

- `sisso_tools/`
  - `export_train_dat_all.py`  
    Convert CSV data into SISSO-style `train.dat` files for G0/G1/G5.
  - `export_train_dat_split.py`  
    Optional: write consistent train/test splits for SISSO.
  - `plot_sisso_formula_predictions.py`  
    Apply hard-coded SISSO analytical formulas (for G0/G1/G5) on the
    SISSO `train.dat` and compare predicted vs. DFT energies.

- `artifacts/` (initially mostly empty directories)
  - `xgb_models/`  
    Saved XGBoost pipelines (one folder per tag).
  - `xgb_predictions/`  
    Per-tag prediction tables and scatterplots.
  - `shap/`  
    SHAP feature-importance tables, dependence points, summary plots
    and force plots.
  - `sisso/`  
    Outputs related to SISSO formula evaluation.

- `scripts/`
  - `train_all.sh`  
    Convenience wrapper to train G0/G1/G5 in one go.
    **Note:** `PROJECT_ROOT` is currently hard-coded to the original
    author’s macOS path. Edit this variable to your local path before
    using.
  - `eval_seeds_all.sh`  
    Convenience wrapper to run multi-seed evaluation for all tags.

- `tests/`
  - `test_shap_tools.py`  
    Pytest suite for the SHAP helper functions and XGB+SHAP pipeline.

- `utils.py`  
  Shared helpers: project root detection, data loading, logging,
  seeding, and small utility functions.

- `requirements.txt`  
  Python dependencies for the whole project.

## 2. Environment Setup

### 2.1. Python version

- Python **3.9+** (tested with Python 3.10).

### 2.2. Create a virtual environment (recommended)

Example with `conda`:

```bash
conda create -n altcsa python=3.10
conda activate altcsa
```

Or with `venv`:

```bash
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scriptsctivate
```

### 2.3. Install dependencies

From the project root (`AI-TCSA/`):

```bash
pip install -r requirements.txt
```

This installs (among others):

- `numpy`, `pandas`, `scikit-learn`
- `xgboost`
- `shap`
- `scikit-optimize` (`skopt`)
- `matplotlib`, `seaborn`
- `joblib`, `pytest`
- `openpyxl` (Excel read support, used by some scripts)

## 3. Quick Start: Reproduce the Main Pipeline

### 3.1. Train XGBoost models for G0 / G1 / G5

From the project root:

```bash
# G0 model (NO-G0-all.csv)
python modeling/train_models_bayes.py --tag G0

# G1 model (NO-G1-all.csv)
python modeling/train_models_bayes.py --tag G1

# G5 model (NO-G5-all.csv)
python modeling/train_models_bayes.py --tag G5
```

If you omit `--data_path`, each run automatically uses:

- `data/raw/NO-G0-all.csv` for `--tag G0`
- `data/raw/NO-G1-all.csv` for `--tag G1`
- `data/raw/NO-G5-all.csv` for `--tag G5`

Models are saved under:

- `artifacts/xgb_models/G0/`
- `artifacts/xgb_models/G1/`
- `artifacts/xgb_models/G5/`

**Tip:**  
Run `python modeling/train_models_bayes.py --help` to see all options
(e.g. number of Bayesian iterations, random seed, output directory).

#### Optional: train all tags with one script

Edit `scripts/train_all.sh` and set:

```bash
PROJECT_ROOT="/path/to/your/AI-TCSA"
```

Then run:

```bash
bash scripts/train_all.sh
```

---

### 3.2. Check model stability across seeds (optional)

To see how sensitive a given tag is to random seeds:

```bash
# Example: G0
python modeling/eval_models_over_seeds.py --tag G0 --n_seeds 10

# Example: G1
python modeling/eval_models_over_seeds.py --tag G1 --n_seeds 10

# Example: G5
python modeling/eval_models_over_seeds.py --tag G5 --n_seeds 10
```

Results are saved into `artifacts/metrics/` as CSV tables summarizing
R² / RMSE / MAE across seeds.

See `python modeling/eval_models_over_seeds.py --help` for all flags
and output options.

---

### 3.3. Plot predicted vs. DFT Gₙ(eV) for all tags

After the three models are trained:

```bash
python xgb_analysis/plot_xgb_predictions.py
```

This reads:

- XGB models from `artifacts/xgb_models/G*/`
- Raw data from `data/raw/NO-G*-all.csv`

And writes:

- Per-tag prediction CSVs under `artifacts/xgb_predictions/`
- Scatter plots (`y_true` vs `y_pred`) under
  `artifacts/xgb_predictions/plots/`

## 4. SHAP Analysis

All SHAP scripts assume the XGB models are already trained and saved
in `artifacts/xgb_models/G*/`.

### 4.1. Global SHAP feature importance & summary

```bash
python xgb_analysis/shap_summary_xgb.py
```

For each tag (`G0`, `G1`, `G5`), this will:

- Load the corresponding pipeline from `artifacts/xgb_models/<TAG>/`
- Re-compute predictions on the full dataset
- Compute SHAP values using `TreeExplainer` (fallback to
  `KernelExplainer` if needed)
- Save:

  - `artifacts/shap/tables/shap_G<TAG>_xgb_feature_importance.csv`
  - `artifacts/shap/plots/shap_G<TAG>_xgb_summary_bar.png`
  - `artifacts/shap/plots/shap_G<TAG>_xgb_summary_beeswarm.png`

---

### 4.2. SHAP dependence plots (per feature)

```bash
python xgb_analysis/shap_dependence_xgb.py
```

For every (tag, feature) pair, this script:

- Stores a long-format CSV of points:

  - `artifacts/shap/dependence_points/shap_points_G<TAG>.csv`

- Produces dependence plots:

  - `artifacts/shap/dependence_plots/shap_dep_G<TAG>_<feature>.png`

Each plot is:

- x-axis: raw feature value
- y-axis: SHAP value of that feature
- color: feature value
- trend line: fitted polynomial (with optional piecewise fit for
  selected G1 descriptors) and R² annotation.

---

### 4.3. SHAP force plots (per sample / per catalyst)

#### Batch force plots (first N samples per tag)

```bash
python xgb_analysis/shap_force_xgb_batch.py
```

This generates (for each tag):

- `artifacts/shap/force_plots/shap_G<TAG>_force_sample<idx>.png`

Each PNG is a `shap.force_plot` for a single sample, using
feature labels like `Rd-0.07=77.6`.

#### Force plots for selected catalysts on G0

```bash
python xgb_analysis/shap_force_catalysts.py
```

This script:

- Reads `data/raw/NO-G0-all.csv`
- Selects specific catalysts (list is defined inside the script)
- For each catalyst, picks one representative row
- Prints for each:

  - base_value (expected value)
  - sum(shap)
  - base_value + sum(shap)
  - model prediction f(x) for that sample

- Saves a force plot per catalyst to:

  - `artifacts/shap/force_plots/shap_G0_force_<catalyst>_idx<idx>.png`

You can edit the `TARGET_CATALYSTS` list inside
`xgb_analysis/shap_force_catalysts.py` to focus on other catalysts.

## 5. SISSO-Style Analytical Formulas

This part helps bridge ML models and interpretable analytic descriptors.

### 5.1. Export SISSO `train.dat` files

```bash
python sisso_tools/export_train_dat_all.py
```

This will create, for each tag, a directory:

- `data/sisso/G0/train.dat`
- `data/sisso/G1/train.dat`
- `data/sisso/G5/train.dat`

Each `train.dat` is SISSO-compatible:

```text
name  property  f1  f2  ...
```

where:

- `name` is taken from the catalyst ID (if available)
- `property` is Gₙ(eV)
- `f1, f2, …` are descriptor values.

Optional: if you also want train/test splits tailored for SISSO, run:

```bash
python sisso_tools/export_train_dat_split.py
```

(Train/test split files are written into `data/sisso/` with
tag-specific names.)

---

### 5.2. Evaluate SISSO analytical formulas

Once `train.dat` files exist:

```bash
python sisso_tools/plot_sisso_formula_predictions.py
```

For each tag, this script:

- Reads `data/sisso/G*/train.dat`
- Applies the hard-coded SISSO formulas (G0 / G1 / G5)
- Computes MAE / RMSE / R² on the full dataset
- Saves:

  - Prediction tables: `artifacts/sisso/predictions/pred_G<TAG>_formula.csv`
  - Scatter plots of DFT vs formula prediction:
    `artifacts/sisso/plots/fig_formula_G<TAG>.png`

This allows direct comparison of SISSO descriptors vs. the XGB models.

## 6. Running Tests

To make sure the SHAP pipeline and utilities behave as expected:

```bash
pytest -v
```

This will run:

- `tests/test_shap_tools.py`

Note: Running the full test suite may invoke SHAP and XGBoost on small
dummy data; ensure `xgboost` and `shap` are correctly installed
(covered by `requirements.txt`).

## 7. Notes & Tips

- All Python scripts are written to work with **relative paths** based
  on the project root. Always run commands **from the repository root**
  (the directory containing `README.md` and `requirements.txt`).
- The only hard-coded absolute paths are in the shell scripts under
  `scripts/`. Edit `PROJECT_ROOT` there to point to your local clone,
  or ignore those scripts and call the corresponding Python modules
  directly as shown above.
- Random seeds are wired into the main scripts (typically `2025`),
  so results should be reproducible across runs given the same
  environment and versions.

If you encounter any issues running a specific script, check:

1. That your current working directory is the project root  
2. That all dependencies (`pip install -r requirements.txt`) are
   installed  
3. That the expected input files under `data/raw/` or `data/sisso/`
   exist.
